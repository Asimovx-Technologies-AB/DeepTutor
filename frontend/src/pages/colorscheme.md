DeepTutor Color Scheme

Color Direction

DeepTutor uses a warm, calm, educational palette built around:

Warm Cream

Deep Ink

Sage Green

Apricot Orange

Muted Lavender

The palette should feel warm, intelligent, friendly, calm, andpremium.

60%  Warm Cream / White

Primary Meaning

Apricot Orange → Action / Tutor / Next Step
Sage Green     → Learning / Progress / Mastery
Deep Ink       → Knowledge / Typography / Structure
Lavender       → Secondary / Creative emphasis
Warm Cream     → Calm learning environment

Color Usage Rule

Keep the interface primarily warm neutral.

Use:

Orange for what the user should do next.

Green for what the user has learned or completed.

Ink for important information.

Lavender only as a secondary accent.

Cream/white for the main visual environment.

Avoid making blue or purple the dominant brand color. Avoid excessivegradients and highly saturated colors.
